# Sales Performance Dashboard - Power BI

## Project Overview
Developed an interactive Sales Performance Dashboard using Power BI and the Superstore dataset to analyze sales performance, profitability, regional trends, and top-performing products.

## Tools Used
- Power BI
- DAX
- Excel

## Features
- KPI Cards (Total Sales, Total Profit, Total Orders, Average Sales, Profit Margin)
- Sales by Region Analysis
- Yearly Sales Trend
- Category-wise Sales Distribution
- Top 10 Products by Sales
- Interactive Slicers (Region, Category, Segment)

## Key Insights
- West region generated the highest sales.
- Technology category contributed the highest revenue.
- Profit Margin was approximately 12.47%.
- Top products significantly contributed to overall sales.
